# Historical places of Uzbekistan

## Описание

**HistoricalPlacesOfUzb** — это Windows Forms приложение на платформе .NET Framework 4.7.2, предназначенное для ознакомления пользователей с историческими местами Узбекистана. Программа предоставляет интерактивную карту, позволяющую выбирать регионы и просматривать информацию о достопримечательностях каждого региона.

## Основные возможности

- Интерактивная карта Узбекистана с выбором регионов.
- Просмотр списка исторических мест по каждому региону.
- Отображение изображений, описаний и названий объектов.
- Удобная навигация между объектами внутри региона.
- Авторизация администратора (форма входа).
- Современный графический интерфейс (на узбекском языке).

## Требования

- Windows 7/8/10/11
- .NET Framework 4.7.2

## Установка и запуск

1. Клонируйте репозиторий:
2. Откройте проект в Visual Studio 2022.
3. Соберите и запустите проект (`F5`).

## Использование

1. На главной форме выберите интересующий регион.
2. Ознакомьтесь с историческими местами, используя кнопки навигации.
3. Для возврата к карте используйте соответствующую кнопку.
